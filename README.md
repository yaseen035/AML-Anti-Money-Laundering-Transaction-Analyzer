# Anti-Money Laundering Transaction Analyzer

An academic project using the Elliptic Bitcoin Transaction Dataset.

## Technologies
- Python
- SQLite
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly

## Models
- Logistic Regression
- Random Forest
- Isolation Forest

## Features
- Transaction database
- Statistical analysis
- Machine learning predictions
- Risk scoring
- AML alert generation
- Interactive dashboard

## Dataset
Elliptic Bitcoin Transaction Dataset:
https://www.kaggle.com/datasets/ellipticco/elliptic-data-set

The original dataset is not included in this repository.
Please obtain it from its source and check its licence before reuse.

## Important
Predictions are experimental and are not proof of criminal activity.
All high-risk results require human review.
